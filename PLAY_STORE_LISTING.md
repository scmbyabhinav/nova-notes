# NOVA Notes — Play Store Listing Draft

## App name
NOVA Notes

## Short description
Fast, private, offline-first notes, checklists, folders, tags and search.

## Full description
Capture ideas before they disappear.

NOVA Notes is a clean, fast note-taking app designed for everyday capture
without forcing you into an account or a complicated workspace.

### Capture
- Write notes quickly
- Create checklists
- Organize ideas as you go
- Edit and autosave locally

### Organize
- Folders
- Tags
- Favorites
- Pinned notes
- Archive and trash
- Grid or list views

### Find
- Search note titles, content and tags
- Filter by favorites, pinned, archived and note type

### Personalize
- Light mode
- Dark mode
- AMOLED-friendly dark design
- Clean, distraction-free interface

### Privacy
NOVA is designed around a local-first experience. App-lock and biometric
authentication can protect access to the app.

### Backup
Portable backup and restore capabilities are being prepared so your notes
can remain under your control.
