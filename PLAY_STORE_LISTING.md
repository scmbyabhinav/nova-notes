# ORAH — Google Play Store Listing Draft

## App name

ORAH

## Short description

Fast, private, offline-first notes, checklists, folders, tags and search.

## Full description

Capture ideas before they disappear.

ORAH is a clean, fast note-taking app designed for everyday capture without
forcing you into an account or a complicated workspace.

### Capture

- Write notes quickly
- Create checklists
- Organize ideas as you go
- Edit and autosave locally
- Add basic attachments

### Organize

- Folders
- Tags
- Favorites
- Pinned notes
- Archive and trash
- Grid or list views

### Find

- Search note titles, content and tags
- Filter by favorites, pinned, archived and note type

### Personalize

- Light mode
- Dark mode
- AMOLED-friendly dark design
- Clean, distraction-free interface

### ORAH Pro

Optional Pro plans unlock selected advanced features, including:

- OCR
- Smart capture/detection
- Advanced search operators
- PDF, Word and Excel export
- Premium templates

Monthly, Yearly and Lifetime purchase options are supported in the app. Prices
are supplied by Google Play and may vary by region.

### Privacy

ORAH is designed around a local-first experience. App-lock and biometric
authentication can protect access to the app.

### Backup

Portable local backup and restore capabilities are available in the project.
Cloud sync is not currently offered.
